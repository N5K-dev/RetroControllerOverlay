Uso en OBS Studio (Stream)

• Método 1 (Directo en OBS): Añade este index.html como Fuente de Navegador (Archivo local), haz clic derecho → Interactuar y pulsa F2 (o pasa el ratón) para configurarlo ahí mismo. Se guarda automáticamente.

• Método 2 (Configurar en Chrome → llevar a OBS): Configura tu mando aquí y pulsa Copiar URL para OBS. En OBS, desmarca "Archivo local" y pega la URL (file:///...#cfg=...) o pega el JSON abajo.

• Atajos: F2 abre/cierra este panel · ?lock=1 oculta el botón flotante por completo en stream.
